# one line install script for linux environment setup (x86_64 arm64)

```bash
curl https://raw.githubusercontent.com/Araxeus/sync/refs/heads/main/setup-linux-env.sh | bash
```

only the user account that runs this script will be affected. It will not affect other users on the system.

##  List of installed tools

* [vendor](https://github.com/Araxeus/vendorfiles-rs)
* [ls-interactive](https://github.com/Araxeus/ls-interactive)
* [micro](https://github.com/zyedidia/micro)
* [ripgrep](https://github.com/BurntSushi/ripgrep)
* [fzf](https://github.com/junegunn/fzf)
* [fd](https://github.com/sharkdp/fd)
* [bat](https://github.com/sharkdp/bat)
